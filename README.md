# Series02-Python-Sinusoidal Signals

## Objective

* Generate and visualize sinusoidal signals using Python, NumPy, and Matplotlib. 
* Improve code organization, visualization 
* Practicing Git branching and collaborative code review.

## Branching and Development

The assignment was based on three progressive versions for sinusoidal signal waves, which was done using separate Git branches.  

- **`draft-version`** – Generated and visualized a 1 Hz sine wave with appropriate labels and a title.
- **`better-version`** – Added a 1 Hz cosine wave to sine wave with the phase shift 0, used two y-axes, combined the legends, and saved the visualization as a PDF.
- **`final-version`** – Created a reusable `sinusoid()` function with the required parameters and generated two signals with different frequencies.

Git commits and pull requests were used to track changes and receive teammate feedback for needed improvements.

## Main Points

- Represented a sine wave mathematically using amplitude, frequency, and phase.
- Generated a time array using NumPy.
- Created sine and cosine signals for comparison.
- Visualized both signals using Matplotlib.
- Used two y-axes to display sine and cosine amplitudes.
- Added titles, labels, and a combined legend.
- Saved the visualization as a PDF file.
- Practiced GitHub branching, commits, and pull requests for code review.
